# 希尔薇歌单管理试行版

管理页直接读写本仓库的 `catalog.json`，保存后由 GitHub Pages 自动发布。
正式网站尚未切换到这份试行歌单。没有接入额外付费服务器。

专用管理链接需要仓库所有者签发的 fine-grained personal access token，只授权本仓库的 Contents 读写；不要使用拥有所有仓库权限的凭证。
凭证只放在私有链接的片段内，管理页读入内存后清除地址栏片段。不要把私有链接、凭证、日志或个人资料提交到本仓库。
用页面内的“复制管理链接”保存入口，换手机或电脑后直接打开完整链接。

歌曲保留稳定编号、回收站、创建时间。冲突时要求刷新，不覆盖另一台设备的更新；断线时核对操作编号，不盲目重试。
“已保存”指文件已经写入 GitHub；“已发布”需要公开歌单返回同一版本。记录每次保存的 Git 历史，另可导出 JSON 备份。

大陆多节点检查只能说明测试当时的连通性，不能承诺所有地区和运营商始终可用。
