准备你的专用管理链接

这一步只需设置一次。之后手机、电脑打开你保存的完整链接，就能整理歌单，不需要每次登录 GitHub。

1. 签发这份歌单的专用授权

GitHub 要求由账号本人在设置页签发。下面已填好名称、有效期和文件读写权限。

打开 GitHub 授权设置
  1. Repository access 选择 Only select repositories，只勾选 sylvie-songbook-admin。
  2. 确认 Contents 为 Read and write。默认有效期 365 天，到期后需要换一条授权链接。
  3. 点击 Generate token，把生成的内容复制到下方。

2. 生成可以直接打开的管理链接

授权仅用于向 GitHub 验证与保存，不写入公开网页或浏览器持久存储。

进入歌单管理
